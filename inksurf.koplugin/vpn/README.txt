Put your own OpenVPN config here:

  vpn/<provider>.ovpn    the .ovpn file (any provider: Express, Nord, etc.)
  vpn/<provider>.auth    2 lines: line 1 = username, line 2 = password
                         (NordVPN/ExpressVPN: the "service" / "manual config"
                          credentials, NOT your account password)

If there are several .ovpn files, pick one under Settings -> VPN.

These files are NOT part of the package and are never uploaded anywhere.
